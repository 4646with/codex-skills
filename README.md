# Codex macOS `gh` TLS Skill

This repository contains a Codex skill for diagnosing and repairing GitHub CLI TLS errors that occur in Codex on macOS.

## Install

Copy or clone this folder into `~/.codex/skills/codex-macos-gh-tls`, then invoke it with `$codex-macos-gh-tls` or let Codex select it automatically when the task matches.

See [`SKILL.md`](SKILL.md) for the diagnostic workflow and safety boundaries.
